LifeTrack Design System

A premium, government-ready visual language for a longitudinal livelihood-outcomes platform. Built on one idea: this product is a living public record, not a SaaS dashboard.

0. Concept — "The Ledger"

The organizing metaphor: an official case ledger, not a startup dashboard. Verification = a stamp. Self-reported data = a handwritten note. The trainee timeline = a bound record's spine. Every token below serves this idea.

A government tracks a citizen's livelihood the way a registrar keeps a case file: dated entries, some officially stamped, some provisional, accumulating over years. That's the reference object for this entire system — not analytics software.

3. Typography

One superfamily, two cuts. Plex Serif marks anything about a person's recorded history (names, timeline headlines); Plex Sans handles all system chrome. Plex Mono appears only on literal ID codes.

Plex Serif

Trainee names, page titles, timeline headlines. Carries the "ledger" warmth.

Plex Sans

All UI chrome, body text, tables, buttons, nav, data.

Plex Mono

Trainee ID / verification reference codes only — never decorative labels.
