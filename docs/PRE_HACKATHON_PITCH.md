## **[0:15-2:30] Live Demo: Core Features (2:15 min)**

### **FEATURE 1: Verification Levels (Real Confidence in Data)**
**[0:15-0:35]** Login as Government → Dashboard
- Point to **Verification Level System**: L0 (self-report) → L5 (official government record)
- *"Every outcome has a confidence level. L0 is 'trainee says.' L5 is 'government verified.' We show both."*
- Show **Outcomes Known KPI**: 78% known, 22% still unknown
- *"Transparency. Not hiding the gaps."*

### **FEATURE 2: Outcome Tracking with History**
**[0:35-0:55]** Switch to Provider → Trainees List
- Click one trainee → **Timeline view**
- Show events: Certification → Employment start → Wage milestone → Employer verification
- Show **Verification badge progression**: "L1 Sep 15 → L2 Sep 20 (Field agent) → L4 Oct 1 (Employer verified)"
- *"Every trainee's journey is visible. Verification happens in real-time."*

### **FEATURE 3: Automated Follow-Up Escalation (Multi-Channel)**
**[0:55-1:15]** Click **Mock Phone** (`/dev/phone`)
- Select trainee: Show message thread
- *"Lakshmi didn't respond on WhatsApp. System auto-escalated to SMS. Still no response. Then IVR. Then field agent flag."*
- Show 4-step ladder: WhatsApp → SMS → IVR → Field Agent Call
- *"We don't give up. The system reaches out across 4 channels automatically."*

### **FEATURE 4: Risk Scoring with Root Causes**
**[1:15-1:35]** Switch to Counsellor role
- Show trainee with **Risk Score 78 (High)**
- Break down factors inline: *"Low wage (-20 pts), Skills gap (-18 pts), Unreachable 14 days (-15 pts)"*
- Show **Recommended Action**: Bridge course
- *"Counsellor doesn't guess. The system shows exactly what's driving risk and suggests the fix."*

### **FEATURE 5: Employer One-Click Verification**
**[1:35-1:50]** Switch to Employer role
- Show **Verification Link Dashboard**
- *"Employer gets a link. One question: 'Is this trainee employed?' Clicks 'Yes' → Trainee's badge jumps to L4. Done."*
- Show **Verification Stats**: Pending count, response rate, confirmed verifications
- *"Employers verify in seconds. Data syncs immediately to government."*

### **FEATURE 6: Government Equity Analysis**
**[1:50-2:10]** Back to Government Dashboard
- Scroll to **Equity Breakdown**
- Show gender split: Female 68%, Male 72%, Other 60%
- Show age bands: 18-24 → 65% placement, 25-34 → 78% placement
- *"We flag equity gaps. If any group drops below 60%, government is alerted. Targeted interventions."*

### **FEATURE 7: Real-Time Dashboard Updates**
**[2:10-2:30]** Refresh dashboard
- *"Notice: Placement rate updated in real-time. Why? Just marked one trainee verified."*
- Show **Alert System**: Flags for underperforming providers, pending verifications, disputed outcomes
- *"Government gets live alerts. Can act same-day, not wait for monthly reports."*

## **[2:30-3:30] What Makes This Different (1:00 min)**

### **Why LifeTrack Matters**

**Most skilling programs:**
- Track enrollment (how many trained?)
- Hope for outcomes (fingers crossed)
- Never verify (no idea what happened)

**LifeTrack:**
- Tracks **every outcome in real-time**
- **Verifies** with employers & government
- **Acts** when someone is at risk (before they drop out)
- Shows **equity gaps** and fixes them

### **In 36 Hours: Scale This**

**Current:** 50 trainees, 1 state, 20 alumni data sources  
**Hackathon Goal:** 500 trainees, 3 states, 200+ alumni data sources  
**Vision:** 500K+ trainees, all states, live outcomes network

### **The Real Innovation**

We're not building a reporting tool. We're building **infrastructure for accountability.**

- Government sees real placement rates (not promises)
- Providers improve because outcomes matter (funding follows results)
- Employers verify once, data flows everywhere
- Trainees know their data is protected (consent matrix built-in)
- **Counsellors intervene early** (before crisis, not after)
